# Tactical Archive PC（Windows デスクトップ版）

ブルーアーカイブ戦術対抗戦の対戦履歴を、**PC版ブルーアーカイブのスクリーンショット**から記録・検索する Windows 用アプリです（非公式）。

Web版（`docs/`）の処理をコピーして、デスクトップ向けの機能を足しています。Android版・Web版・PC版はそれぞれ別のアプリです。

## できること

- **16:9 と 4:3 の両方に対応**：スクリーンショットのアスペクト比（16:9 / 4:3）を自動認識し、基準サイズ（16:9 = 1920×1080、4:3 = 1600×1200）にリサイズして読み取ります。トリミング位置は組み込み済みなので初回調整は不要です（設定から再調整・初期値に戻すこともできます）。
- **スクリーンショットフォルダの巡回**：設定でフォルダを登録し、「フォルダを巡回」（または `Ctrl+Shift+P`）を押すと、まだ読み込んでいない画像を古い順に取り込みます。
  - 処理したファイル（パス＋更新日時）は記録し、次回は飛ばします。登録済みの戦績はファイル名でも除外します。
  - 高速モードを ON にすると、確認が必要な画像だけ確認画面で止まります。
  - 終わると「取り込み N件・スキップ（対戦履歴以外）M件・アスペクト比違い（16:9 / 4:3 以外）K件」を表示します。
- **対戦履歴ではない画像の自動スキップ**：戦闘履歴（リザルト）画面でなければ、確認画面を出さずに飛ばします（設定で OFF にできます）。
- **取り込み済みスクショの整理**（設定で ON、初期は OFF）：巡回で取り込んだ画像を、登録フォルダ内の「取り込み済み」フォルダ（名前は変更可）へ移動します。オプションでファイル名を「日付_相手名_WIN/LOSE_攻撃/防衛.png」に変えます（使えない文字は `_` に置換、同名は `_2`, `_3` …）。対戦履歴以外・アスペクト比違いの画像は動かしません。処理済みの記録も移動先に合わせて更新し、移動先フォルダは巡回の対象外です。
- **自動バックアップ**：バックアップ先フォルダ（OneDrive などの同期フォルダ）を選ぶと、「起動時」「巡回後（1件以上取り込んだとき）」にフルバックアップを保存します。形式は Web版・Android版と同じ JSON で、ファイル名は `TacticalArchive_Full_YYYYMMDD_HHMMSS.json`。世代数（初期 10）を超えた古いものは自動で削除します（この命名規則のファイルだけが対象）。最後に成功した日時は設定画面に表示し、失敗したら通知します。
- **分析タブ**：攻撃/防衛の切り替えと期間（全期間・直近30日・任意期間）の絞り込みができます。表示内容は、自軍編成（並び順を問わない6人の組み合わせ）ごとの使用回数と勝率／防衛率、相手の編成ごとの対戦数と勝率、生徒別の採用数と勝率（自軍・相手を切り替え）、よく当たる相手のランキング、日別の戦数と勝率の推移です。行や棒をクリックすると、該当する戦績を攻撃/防衛タブで表示します（タブ上の「解除」で戻ります）。
- **一括修正**（設定）：
  - 対戦相手名の一括置換：件数を確認してから実行します。オプションで修正辞書にも登録できます。
  - 生徒の一括置換（統合）：統合元を図鑑から削除し、顔データを統合先に移すこともできます。
  - どちらも実行前に、今のデータを `data\pre-edit-backups\` に自動で保存します（「リストア」で元に戻せます）。
- **相手の手持ち生徒**：対戦相手の名前を長押し、または右クリックすると、その相手が使った生徒をストライカー／スペシャル別に回数順で表示します。分析タブの「よく当たる相手」からも開けます。
- 攻撃/防衛タブ、検索、生徒図鑑、プリセットアイコン、バックアップ/リストア（Web版・Android版と同じ JSON 形式）、CSV出力、対戦相手名の修正辞書など、Web版の機能はそのまま使えます。
- 文字認識（Tesseract.js と日本語データ）とアイコンフォントを同梱しているので、オフラインでも動きます。

## 使い方

1. `TacticalArchivePC.zip` を好きな場所に解凍し、`TacticalArchivePC` フォルダの中の `TacticalArchivePC.exe` を起動します（インストール不要）。
2. 画面の比率（16:9 / 4:3）を選んで「はじめる」。
3. 「設定 → 取り込み → スクリーンショットフォルダ」で、PC版ブルーアーカイブのスクリーンショットの保存先を選びます。
4. 「取り込み」タブの「フォルダを巡回」を押します。

ドラッグ＆ドロップ・画像の選択・`Ctrl+V` での貼り付けでも読み込めます。

### データの保存場所

`TacticalArchivePC.exe` と同じフォルダ内の `data\`（「設定 → 詳細・トラブル対応 → 保存フォルダを開く」で開けます）

| ファイル | 内容 |
| --- | --- |
| `IndexedDB/`、`Local Storage/` | 戦績・生徒辞書・設定（Web版と同じ形式） |
| `config.json` | 登録したフォルダ、サブフォルダを巡回するか、整理・自動バックアップの設定 |
| `pre-edit-backups/` | 一括修正の直前のバックアップ（最新 20 件） |
| `processed-files.json` | 巡回で処理したファイルの記録（「設定 → 詳細・トラブル対応 → 処理済みの記録をリセット」で消せます） |
| `result-detection-log.jsonl` | リザルト判定のログ（画像ごとの判定値） |

データは exe と同じフォルダの `data\` に保存されるため、PCを汚さずポータブルに利用できます。

- **バージョンアップ**：新しい zip を同じ場所に解凍して上書きします。zip に `data\` は入っていないので、データはそのまま残ります。
- **v1.1.4 以前（exe 1つの版）から移る場合**：古い exe と同じフォルダに zip を解凍すると（`…\TacticalArchivePC\TacticalArchivePC.exe` になる）、初回起動時に古い exe の横の `data\` を自動でコピーします。別の場所に解凍した場合は、古い `data\` フォルダを `TacticalArchivePC.exe` の横へ手動でコピーしてください。

## リザルト画面の判定

組み込みのトリミング位置を使い、次の値を測ります（`renderer/app.js` の `analyzeResultScreen`）。

| 値 | 内容 |
| --- | --- |
| `modalWhite` | リザルト枠の中の白い画素の割合 |
| `outsideWhite` / `lumaContrast` | 枠の上下（暗くなった背景）の白い画素の割合／枠の内と外の明るさの差 |
| `gold` / `grey` | WIN（金色）/ LOSE（灰色）の位置の画素数 |
| `texturedSlots` | 12 個の生徒アイコンの位置のうち、絵がある（平坦でない）数 |
| `attackCorr` | 攻撃アイコンのテンプレートとの一致度（ZNCC） |

判定：`白い枠あり` かつ `生徒アイコンの絵あり` かつ（`攻撃アイコンが強く一致` または（`WIN/LOSE あり` かつ `枠の外が暗い`））

しきい値は `renderer/result-detection.js` にまとめてあります。誤判定があったら「設定 → 詳細・トラブル対応 → リザルト判定ログを開く」で値を確認して調整してください。

## ビルド手順

必要なもの：Node.js 20 以上、Windows

```bash
cd pc-app
npm install
npm start          # 開発用に起動
npm run dist       # dist/win-unpacked/ を作り、../release/TacticalArchivePC.zip にまとめる（配布用）
npm run dist:portable  # 1ファイルの portable exe を作る場合（起動のたびに一時フォルダへ展開するので遅い）
npm run dist:nsis  # インストーラー版を作る場合
```

`npm install` で electron の実行ファイルがダウンロードされない場合（npm の install script 制限）は、`node node_modules/electron/install.js` を実行してください。

`npm start` / `npm run dist` の前に `scripts/copy-vendor.js` が `node_modules` から次のものを `renderer/vendor/` にコピーします（git には入れません）。

- tesseract.js 5.1.1（本体・worker）、tesseract.js-core 5.1.1（LSTM 版。wasm を埋め込んだ `.wasm.js` だけ）
- 日本語学習データ `jpn.traineddata.gz`（`@tesseract.js-data/jpn` の 4.0.0_best_int。Web版が CDN から読むものと同じ）
- Font Awesome Free 6.4.0（css と woff2。ttf とブランドアイコンは使わないのでコピーしない）

## 構成

```
pc-app/
├── main.js              Electron メインプロセス（app:// で画面を配信、フォルダ・処理済み記録・ログの IPC）
├── preload.js           画面に渡す API（window.taDesktop）。contextIsolation 有効、nodeIntegration 無効
├── renderer/
│   ├── index.html / index.css / app.js   Web版のコピーを PC 用に変更したもの
│   ├── students_data.js / default_roster.json / icon.png
│   ├── result-detection.js               リザルト判定のしきい値
│   ├── pc-desktop.js / pc-desktop.css    フォルダ巡回・整理・自動バックアップ・設定・ダイアログ
│   ├── pc-analysis.js                    分析タブ
│   ├── pc-tools.js                       一括修正
│   └── vendor/                           同梱ライブラリ（ビルド時にコピー）
└── scripts/copy-vendor.js
```

## 開発用

- `F12` / `Ctrl+Shift+I`：開発者ツール（認識のログを確認できます）
- `F5` / `Ctrl+R`：再読み込み
- 環境変数 `TA_USER_DATA=<フォルダ>` を付けて起動すると、データを別のフォルダに保存します（テスト用）。
